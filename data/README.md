# Data inventory

## Raw data

`raw/` contains the 12 compressed per-sample tables associated with GEO accession [GSE218000](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE218000).

## Processed data

`processed/UC_CK_CD.csv` is the combined Control, Crohn's disease, and ulcerative colitis table used by the project analyses.

The processed file is approximately 78.2 MB. Clone the repository rather than relying on GitHub's browser preview for this file.

## Provenance

These files were copied from the C&S Bio Group 1 Google Drive project folder on 2026-08-01. Consult the root README and the exported project outline in `docs/` for assay structure, sample counts, marker selection, and analysis limitations.
